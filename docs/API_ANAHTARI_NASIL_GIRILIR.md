# Gemini API anahtarı — güvenli kurulum

## ÖNEMLİ
API anahtarını sohbete, e-postaya veya ZIP içine yazmayın.
Anahtar yalnızca sizin telefonunuzda/emülatörünüzde saklanır.

## Adımlar
1. https://aistudio.google.com/apikey adresinden ücretsiz anahtar alın.
2. Bu V6 paketini yeni klasöre çıkarın ve UYGULAMAYI_AC.cmd ile kurun.
3. Uygulamada: Ayarlar → AI Asistan → Gemini API Anahtarı
4. Anahtarı yapıştırıp Kaydet deyin.
5. AI sayfasını açın — çevrimiçi mod hazır olmalı.

Anahtar cihazın SharedPreferences alanında tutulur; kaynak koda gömülmez.
Silmek için aynı ekrandan Sil seçin.

Anahtar yoksa ücretsiz çevrimdışı rehber çalışmaya devam eder.
